# Installation guide moved

The maintained installation guide is now [INSTALATION.md](../../../../INSTALATION.md)
at the repository root. It covers OpenCode V2, Codex, Windows with WSL, runtime
provisioning, policy/configuration merging, verification, rollback and the main
contracts for adapting another CLI.

Run the installer from the source checkout: `bash install.sh --host opencode`
or `bash install.sh --host codex`. The repository README provides a ready-to-use
agent installation prompt.
