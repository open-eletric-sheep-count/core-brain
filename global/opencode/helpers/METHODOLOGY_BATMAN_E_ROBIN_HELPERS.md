# METHODOLOGY_BATMAN_E_ROBIN_HELPERS

Helper for menu option 5 (`Batman e Robin`). Loaded by the ORACLE when the USER chooses this flow. Complements the `batman-e-robin` skill.

## What it is

Batman and Robin: the ORACLE (Batman) thinks, architects, researches, decides, and tests; the DEVELOPER (Robin) executes safe mechanical work from a precise brief. No ARCHITECT, no tribunal. Load the `batman-e-robin` skill via the skill tool and execute it (6 steps: Trigger → THINK → PLAN → DO → TEST → ACCEPT).

## Rules

- Executes the `batman-e-robin` skill as-is (frozen); inside it no ARCHITECT, no tribunal, no `be-judge`; Robin never contacts the USER (ORACLE is sole channel); Robin MUST NOT invent, add, or decide anything outside the brief.
