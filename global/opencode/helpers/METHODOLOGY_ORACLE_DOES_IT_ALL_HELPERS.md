# METHODOLOGY_ORACLE_DOES_IT_ALL_HELPERS

Helper for menu option 3 (`ORACLE does it all`). Loaded by the ORACLE when the USER chooses this flow. Complements the `be-a-master-developer` skill.

## What it is

Direct execution: load the `be-a-master-developer` skill via the skill tool and become the master developer for the request. The agent does everything directly (no layered flow, no debate, no tribunal); tools and sub-agents are optional aids; the result goes directly to the USER.

## Rules

- Executes the `be-a-master-developer` skill as-is (frozen); its mode applies to the task it was selected in.
